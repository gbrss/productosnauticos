# Productos Náuticos — Astro.js

Sitio web de **productosnauticos.cl** construido con **Astro 5** + **Tailwind CSS**.

## Cómo correr

```bash
npm install
npm run dev
```

Abre http://localhost:4321

## Desplegar en Vercel

1. Sube este proyecto a GitHub
2. Importa en [vercel.com/new](https://vercel.com/new)
3. Framework: Astro (se detecta solo)
4. Deploy

## Estructura

```
src/
├── components/   # Header, Hero, About, Products, Instagram, Footer
├── layouts/      # Layout base
├── pages/        # Rutas
└── styles/       # Global CSS + Tailwind
```
